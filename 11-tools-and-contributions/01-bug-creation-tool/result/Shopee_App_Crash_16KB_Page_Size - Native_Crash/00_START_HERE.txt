🔍 ISSUE SUMMARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem:
   Shopee app crashes immediately on startup when running on Android 15
   devices with 16KB page size configuration.

Root Cause:
   Native libraries (.so files) are not properly aligned for 16KB page
   boundaries. App is built for 4KB pages only.

Verification:
   ✅ Same APK works fine on 4KB page size devices (API 34)
   ❌ Same APK crashes on 16KB page size devices (API 35)
   → Confirms issue is specific to 16KB incompatibility

Impact:
   • App completely unusable on 16KB devices
   • Blocks Android 15 (16KB) compatibility testing
   • Will affect future devices using 16KB as default

Teams Involved:
   • @Native-Team (Primary) - Rebuild libraries with 16KB alignment
   • @Build-Team (Secondary) - Update build configuration
   • @Android-Platform-Team (Tertiary) - Verify compliance

   → Add: -Wl,-z,max-page-size=16384

   → Set extractNativeLibs="false" in AndroidManifest.xml
   → Add useLegacyPackaging=false in build.gradle
   → Test on 16KB emulator
