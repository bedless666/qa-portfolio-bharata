The PDP service is incorrectly interpreting logistics/shipping failures as "sold_out" status. Here's what's happening:

1. Item Status in Backend = NORMAL ✅

3. PDP Misinterprets Logistics Errors ❌
   - PDP receives logistics failure responses
   - Instead of handling as shipping configuration issue
   - PDP sets "abnormal_status": "sold_out"
   - This is INCORRECT - item is not sold out, it has logistics issues

WHY THIS IS WRONG:
- "sold_out" implies the item has no stock/inventory
- Actual issue is logistics configuration, not item availability
- Creates confusion: seller sees NORMAL, buyer sees "sold_out"
- Misleading error status prevents proper troubleshooting

WHAT SHOULD HAPPEN:
- PDP should distinguish between item availability and shipping availability
- Use separate status for logistics issues (e.g., "shipping_unavailable")
- Show appropriate error message about shipping configuration
- Do NOT mark as "sold_out" when item status is actually NORMAL
