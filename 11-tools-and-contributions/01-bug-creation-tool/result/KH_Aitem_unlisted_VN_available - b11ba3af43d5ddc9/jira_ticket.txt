*Initial Judgment / Root Cause Analysis:* Backend issue

**Root Cause:**
Multiple infrastructure issues in KH test environment causing item to appear unlisted:

1. **Hardy Routing Error (Primary)**
   - Service: `sellerfulfilment-fulfilmentinfo-test-ph` (note: running in PH but handling KH)
   - Error: `hardy (3025): routing out of range, route region: kh, route index: 0`
   - Query: `SELECT * FROM shop_fm_info_tab WHERE shop_id=1013210527`
   - Impact: Cannot retrieve shop fulfillment configuration

2. **Invalid Address (Secondary)**
   - Error: `unavailable address id|userid=7347400547, address_id=0`
   - Impact: Address validation failures cascade through logistics services

3. **CID Mismatch**
   - Warning: "CID from flag=kh but CID from env=ph"
   - Service in PH environment incorrectly handling KH requests

4. **DNS Error**
   - Error: `lookup fss-searchapi.ssc.test.shopee.kh.com: no such host`
   - Impact: FSS service unreachable

**Error Chain:**
1. PDP requests shop fulfillment info for shop_id=1013210527
2. Hardy routing fails → "routing out of range" for KH
3. Shop fulfillment info unavailable → ERROR_SYSTEM
4. Without fulfillment info, item cannot be listed
5. Item shows as "unlisted" in KH (but available in VN where routing works)

**Impact:**
- Item listing inconsistency between KH and VN regions
- Hardy routing failure for entire KH region
- Shop fulfillment configuration unavailable
- Cross-region testing blocked
