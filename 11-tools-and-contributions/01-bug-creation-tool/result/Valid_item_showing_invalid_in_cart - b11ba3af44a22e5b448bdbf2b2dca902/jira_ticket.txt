*Initial Judgment / Root Cause Analysis:* Backend issue

Technical Analysis:
This is a Cart State Synchronization Issue in the cartservice-core service. The root cause involves multiple interconnected problems:

1. **Add-On Deal Promotion Failure (Primary Issue)**
   - Item (ItemID: 3344815530, ModelID: 2025231470) is part of Add-On Deal promotion (PromoID: 385913276477948)
   - The main item is not properly registered in the cart state
   - Log shows: "fallback all valid subs due to no valid main exists"
   - This causes all sub-items in the Add-On Deal to be invalidated

2. **Expired Promotion Still Active**
   - Item 3144815806 has expired promotion (Type: 313, ID: 385913276477728, ended at 1763630492)
   - price-business service detected: "price status is normal but promotion has ended"
   - Cart still references the expired promotion, causing price calculation mismatches

3. **Configuration Missing**
   - Missing configs in test-KH: "item_model_tag_info_config" and "seller_streaming_session_batch_size"
   - These missing configurations may contribute to incomplete cart item validation

4. **Cache Write Failures**
   - Redis cache operations timing out in promotion-rewardslogistics service
   - Error: "redis_setmany_err: context canceled"
   - Prevents proper discount information from being cached, affecting cart validation

5. **Data Consistency Issues**
   - Mismatched field: total_can_buy_quantity (Expected: 0, Actual: 400)
   - Cart state and item availability data are out of sync

Service Chain:
- cartservice-core-test-kh (Primary failure point)
- price-business-test-kh (Promotion status mismatch)
- promotion-rewardslogistics-test-kh (Cache failures)
