ROOT CAUSE
This is a Cart State Synchronization Issue with multiple contributing factors:

1. **Add-On Deal Main Item Missing (Primary)**
   The main item (ItemID: 3344815530, ModelID: 2025231470) in the Add-On Deal promotion (PromoID: 385913276477948) is not properly registered in the cart state. When the cart service tries to update promotion information, it cannot find the main item, causing the entire Add-On Deal to fail validation. This triggers a fallback mechanism that invalidates all sub-items in the promotion.

2. **Expired Promotion Still Active**

5. **Data Consistency Mismatch**
