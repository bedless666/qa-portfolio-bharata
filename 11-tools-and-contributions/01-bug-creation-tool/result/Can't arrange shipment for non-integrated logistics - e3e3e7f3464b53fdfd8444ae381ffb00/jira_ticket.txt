*Initial Judgment / Root Cause Analysis:* Backend issue

**Technical Analysis:**
Based on log analysis, this is a backend performance/timeout issue in the OMS (Order Management System) service.

**Root Cause:**
The `/api/forder/init` endpoint in OMS service (order-fulfilment) is taking more than 10 seconds to respond, causing the sellerfulfillment-shipment service to timeout with error code 120510041 ("context deadline exceeded").

**Service Call Chain:**
1. Seller Center UI → POST /api/fulfillment/shipment/v2/init (sellerfulfillment-shipment service)
2. sellerfulfillment-shipment → POST https://oms.staging.marketplace.co.id/api/forder/init (OMS service)
3. OMS service times out after 10 seconds without responding (status_code=-1)
4. Error propagates back to user
