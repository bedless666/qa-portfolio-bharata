*Initial Judgment / Root Cause Analysis:* Backend issue

Based on log analysis from campaignscene-commonsceneadmin-test-kh service:

**Root Cause:** Configuration Error - Missing Operation Type

The service `campaignscene-commonsceneadmin` does not recognize the operation type "review" when calling GetCsvTemplate API. The error logs clearly show:
- WARN: "unknown operation" with operation=review
- ERROR: "GetCsvTemplate fail" with error "unknown operation review"

- Service: campaignscene-commonsceneadmin-test-kh

- Error Type: Configuration/Validation Error
- Error Code: 10000 (ERROR_UNKNOWN)
- Session ID: 170000000005052
- IDC: sg90

**Analysis:**
The "review" operation type is either:
1. Not configured in the CSV template service's allowed operations list
2. Missing from the operation type enum/constants
3. Not implemented in the GetCsvTemplate handler logic

This is a backend configuration issue where the service needs to add support for the "review" operation type in its CSV template retrieval logic.
