*Initial Judgment / Root Cause Analysis:* Backend issue

**Root Cause:**
Hardy database routing configuration for `shopee_account_address_db` cluster does not include AR (Argentina) region in the supported regions list. The sharding expression only includes: [br, cl, co, id, mx, my, ph, sg, th, tw, vn], but AR is missing.

**Technical Details:**
- Service: `location-userlocation-staging-ar`
- Database Cluster: `shopee_account_address_db`
- Table: `buyer_address_tab`
- Hardy Version: v0.11.0
- CRDS ID: sddl_10007290
- Error Code: Hardy 3027 (eval sharding expression failed)
- User-facing Error: 120030000 (unknown system error), 433300000 (account.address failed)

**Error Chain:**
1. CNSC user attempts to create address for AR shop (user_id: 8093951849, shop_id: 305929322)
2. Request goes through: sellerplatform-gatewayacl-staging-cn → selleraddress-cnmisc-staging-cn
3. Service calls `account.address_pii.create_private_address` (region: AR)
4. Service calls `account.address.internal_create_private_address_without_pii`
5. Hardy routing tries to evaluate sharding expression with region: ar
6. Hardy finds AR is not in configured regions list: [br, cl, co, id, mx, my, ph, sg, th, tw, vn]
7. Hardy returns error: "eval sharding expression failed when use region: ar to format region expression"
8. Error propagates back: 433300000 (account.address failed) → 120030000 (unknown system error)
9. User sees generic error message in CNSC

**Why AR is Missing:**
The Hardy routing configuration (CRDS ID: sddl_10007290) for the `shopee_account_address_db` cluster was created before AR region was added to the platform, or AR was intentionally excluded. The configuration needs to be updated to include AR in the regions list.

**Affected Operations:**
- Create address (internal_create_private_address_without_pii)
- Count addresses (SELECT query with userid filter)
- Any database operations on buyer_address_tab for AR region
- CNSC address management features for AR shops

**Additional Context:**

```

CID from flag=sg but CID from env=cn
```
This suggests CNSC routing might have configuration issues when accessing AR region services.
