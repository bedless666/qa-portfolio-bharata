ROOT CAUSE
The issue is caused by a missing or incomplete feature toggle configuration in the staging environment. The button generation logic in the Seller Fulfilment service attempts to check if the shop is whitelisted for feature "sz_motorcycle_loan_seller" by calling the Feature Toggle service. However, this feature toggle configuration either:
1. Does not exist in the staging environment
2. Has an incomplete schema missing the required "is_in" field

When the feature toggle check fails with error 30030 ("field[is_in] is not exists"), the button action generation code catches this error and returns error 30000 (unknown system error). This causes btn_info_list to be set to null, preventing the UI from rendering the "Arrange Shipment" button even though all other conditions for showing the button are met.
