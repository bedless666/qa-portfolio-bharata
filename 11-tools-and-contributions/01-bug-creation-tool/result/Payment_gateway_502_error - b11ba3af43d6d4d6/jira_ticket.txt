*Summary*:
Can't place order in ID Staging unless using COD payment - Payment gateway returns 502 Bad Gateway error

*Configuration*:
- app / os version: Chrome on Mac OS X
- env (test, staging, live) and country info: Staging, ID
- pfb build: n/a
- account (user / id): user_id=5216310904
- toggles: none

*Impact*
- user impact summary: All users in ID Staging cannot place orders using non-COD payment methods (Credit Card, Debit Card, MarketplacePay, etc.). Only COD payment works. This blocks the entire checkout flow for digital payments.
- test impact summary: QA team cannot test any payment-related features in ID Staging. All payment method verification, payment promotions, and transaction flows are blocked.
- any workaround: Use COD (Cash on Delivery) as payment method

*Initial Judgment / Root Cause Analysis:* Backend issue

**Root Cause:**
MarketplacePay Gateway (SPM) service is unreachable in ID Staging environment. The payment verification service (mpp-bridgeapi) attempts to call SPM API to verify the chosen payment channel, but receives HTTP 502 Bad Gateway error from nginx, indicating the upstream service is down or not responding.

**Technical Details:**
- Service: `mpp-bridgeapi-staging-id` → `MarketplacePay Gateway (SPM)`
- Failed API: `https://gw0.pps.i.staging.marketplacepay.co.id/api/get_payment_channel/`
- Error: `502 Bad Gateway - Connect Upstream Failed`
- SPEX Error Code: `19300999` (ERROR_UNKNOWN)
- Checkout Error Code: `35400002` (error_other_service)

**Error Chain:**
1. User clicks "Place Order" with payment channel 80030 (Credit Card)
2. `mpcheckout-core` calls `payment.mpp.bridge_api.verify_chosen_payment_channel_v2`
3. `mpp-bridgeapi` calls SPM API: `POST https://gw0.pps.i.staging.marketplacepay.co.id/api/get_payment_channel/`
4. SPM Gateway returns: `502 Bad Gateway - Connect Upstream Failed`
5. Payment verification fails with error code `19300999`
6. Checkout process aborts with error: "error_other_service"

**Affected Services:**
- `mpp-bridgeapi-staging-id` - Payment bridge service
- `mppayments-channel-staging-id` - Payment channel info service
- `checkoutpromo-business-staging-id` - Promotion service (blocked by payment error)

**Why COD Still Works:**
COD (Cash on Delivery) payment method doesn't require real-time payment gateway verification, so it bypasses the SPM API call and allows checkout to proceed.
