h2. Problem

Marketplace app crashes on Android 15 devices with 16KB page size (Pixel 8 Pro, etc.)

*Error:* {{Program alignment (4096) smaller than system page size (16384)}}

|| Test || Device || Result ||
| 16KB Device | Pixel 8 Pro API 35 | {color:red}CRASH{color} |
| 4KB Device | Pixel 8 API 34 | {color:green}WORKS{color} |
