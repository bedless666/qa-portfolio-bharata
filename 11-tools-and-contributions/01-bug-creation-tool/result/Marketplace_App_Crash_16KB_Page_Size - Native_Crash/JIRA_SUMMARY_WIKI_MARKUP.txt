h2. Executive Summary

The Marketplace application experienced critical native crashes on Android 15 devices with 16KB page size configuration, specifically affecting Pixel 8 Pro and similar devices. The issue was caused by native library alignment incompatibility with the 16KB system page size. The Native Team successfully developed and deployed a fix, which has been verified and confirmed working by QA team.

{panel:title=Impact Assessment|bgColor=#FFEBE6}
*Severity:* Critical - App completely unusable on affected devices
*Scope:* All Android 15+ devices with 16KB page size configuration
*User Impact:* 100% crash rate on app launch
*Business Impact:* Blocks Android 15 compatibility and future device support
{panel}

h2. Root Cause Analysis

h3. Technical Root Cause

{panel:title=Memory Alignment Issue|borderColor=#FF5630}
*Problem:* Native libraries compiled with 4KB page alignment
*Conflict:* Android 15 devices using 16KB system page size
*Impact:* Memory mapping failure causing SIGSEGV (Segmentation Violation)

The native libraries ({{.so}} files) were built with program alignment set to 4096 bytes (4KB), which is incompatible with devices configured for 16384 bytes (16KB) page size. When the Android system attempts to load these libraries, the memory mapping fails due to alignment mismatch.
{panel}

h3. Affected Components

# *libglog_v2.so* - Logging library
# *libjsi.so* - JavaScript Interface library
# *libshadowhook.so* - Hook framework library
# *libnative-crash.so* - Crash reporting library

h3. Build Configuration Issues

{code:java}
// Problematic configuration
android {
    packagingOptions {
        jniLibs {
            useLegacyPackaging = true  // extractNativeLibs=true
        }
    }
}

// Native libraries alignment: 4096 bytes (4KB)
// System requirement: 16384 bytes (16KB)
// Result: INCOMPATIBLE
{code}

h2. Solution Implemented

h3. Fix Approach

[~ren.jiaxin] implemented the following solution:

# *Recompiled native libraries* with 16KB page alignment support
# *Updated build configuration* to support both 4KB and 16KB page sizes
# *Modified packaging options* for proper library extraction
# *Added compatibility checks* for page size detection

h3. Build Details

*Fixed Build:* {{fix-16kb-1204}}
*Build Date:* 2025-12-03
*Location:* app.sea platform
*Build Type:* Regression build with 16KB support

h3. Technical Changes

{code:bash}
# Native library compilation flags updated
-Wl,-z,max-page-size=16384

# Gradle configuration updated
android {
    packagingOptions {
        jniLibs {
            useLegacyPackaging = false
        }
    }
    
    splits {
        abi {
            enable true
            reset()
            include 'arm64-v8a'
            universalApk true
        }
    }
}
{code}

* (+) Comprehensive testing approach (16KB vs 4KB comparison)
* (+) Clear communication throughout the process

* (-) No automated 16KB compatibility checks in CI/CD pipeline
* (-) Limited documentation on 16KB build requirements
* (-) No proactive testing for Android 15 compatibility

h3. Recommendations
