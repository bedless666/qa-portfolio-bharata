*Initial Judgment / Root Cause Analysis:* Backend issue

Technical Analysis:
The issue originates from the `resource-slotmanagementcore` service where the memory cache system is closed/unavailable. 

Service Call Chain:
1. campaignscene-commonsceneadmin receives approve request
2. Calls promotion.cmt.recruiting.recruiting_admin.reviewer_approve
3. recruiting-recruitingadmin processes the approval
4. Calls resource-slotmanagementcore to reduce slot setting
5. FAILURE: slotmanagementcore cannot access cache (error: "cache:cache_closed")

Root Cause Details:
- Service: resource-slotmanagementcore-staging-id
- Operation: GetValueFromMemoryCache for "slot_category_universe"
- Error: "cache:cache_closed" - The cache infrastructure is not running or connection is closed
- Impact: Cannot locate slot settings, cannot lock slot sheet, cannot reduce slot allocation
- Error Code: 264000014 (Reduce Slot Setting Failed)
