*Root Cause Analysis:*

**Issue Type:** Backend Data Inconsistency - SIP Item Status Synchronization Failure

**Technical Details:**
This is a SIP (Shopee Integrated Platform) cross-border item synchronization issue. In SIP architecture:
- **P-item (Primary item)**: The original item in the primary shop (P-shop)
- **A-item (Affiliated item)**: The synchronized copy in the affiliated shop (A-shop) for cross-border selling

The A-item (Item ID: 2303838543) in the KH A-shop is marked as "unlisted" in the system, but the corresponding P-item is available and properly configured with logistics. This indicates a failure in the SIP item status synchronization mechanism.

**Error Chain:**
1. User attempts to add A-item to cart via `/api/v4/cart/add_to_cart`
2. Request goes to `cart-bff-test-kh` service
3. BFF calls `marketplace.cart_v2.core.add_cart_item` in `cartservice-core-test-kh`
4. Cart service checks item status and finds item is unlisted
5. Error logged: "item_unlisted" for item_id: 2303838543
6. Internal error code 63 (item_unlisted) is converted to Spex error 184803007
7. BFF returns user-facing error 15020015: "Sorry, the item is currently unlisted."

**Service Chain:**
```
Frontend (KH buyer)
  ↓ POST /api/v4/cart/add_to_cart
  ↓ Item: 2303838543, Model: 310001393599, Shop: 1013045290

cart-bff-test-kh
  ↓ marketplace.cart_v2.bff.add_to_cart
  ↓ Calls core service

cartservice-core-test-kh
  ↓ marketplace.cart_v2.core.add_cart_item
  ↓ Validates item status
  ↓ ❌ ITEM_UNLISTED detected
  ↓ Error code: 184803007 (ERROR_ITEM_IS_UNLISTED)

Response: Error 15020015
```

**Root Cause - SIP Synchronization Failure:**

The issue is caused by one or more of the following:

1. **Item Status Not Synchronized**: 
   - P-item status changed to "listed" but A-item status was not updated
   - SIP synchronization job failed or was delayed
   - Item status update event was not propagated to A-shop

2. **A-item Display Settings Misconfiguration**:
   - A-item may have incorrect display settings that override P-item status
   - Fulfillment type or location settings may be blocking the item
   - Item may be blocked for specific regions despite logistics being configured

3. **Database Inconsistency**:
   - A-item record in database shows status as "unlisted"
   - P-item record shows status as "listed"
   - Synchronization mechanism failed to update A-item status
