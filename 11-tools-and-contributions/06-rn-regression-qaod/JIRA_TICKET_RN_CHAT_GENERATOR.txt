h2. Summary

Created a web-based chat template generator tool to streamline RN regression task distribution for QAoD team. The tool generates standardized chat messages for three regression scenarios: Deployment Staging, Staging Regression, and Live Regression, with embedded reference links for version checking and documentation.

{panel:title=Key Features|bgColor=#DEEBFF}
* Three template types: Deployment Staging, Staging Regression, Live Regression
* Quick date fill buttons (Today, Tomorrow, Next Friday/Monday/Wednesday)
* Real-time preview of generated chat
* One-click copy to clipboard functionality
* Collapsible sections for better form organization
* Reference links embedded for version checking and documentation
{panel}

----

h2. Problem Statement

*Before Enhancement:*

*Existing workflow:*
# Manually type chat messages for each regression cycle
# Search for reference links (Release Portal, App versions, JIRA filters)
# Copy-paste from previous messages and update details
# Prone to missing critical information or links
# Time-consuming process (5-10 minutes per message)
# Inconsistent message format across different QA members

{warning}
*Pain Points:*
* Manual typing leads to typos and inconsistencies
* Difficult to remember all required reference links
* Version numbers and dates need manual formatting
* Time-consuming to create messages for multiple regression types
* No standardized template across team
{warning}

*Limitations:*

|| Issue || Impact ||
| Manual message creation | 5-10 minutes per message |
| Missing reference links | Team members need to ask for links |
| Inconsistent format | Confusion in task distribution |
| Version info scattered | Need to check multiple sources |

----

h2. Solution Implementation

*Web-Based Single-Page Application:*

*Description:*
Created a standalone HTML file with embedded CSS and JavaScript that can be opened directly in any browser without server requirements.

*Key features:*
* Tab-based interface for three template types
* Form validation for required fields
* Date helper functions for common date selections
* Live preview with syntax preservation
* Clipboard API integration for easy copying

*Template Types Implemented:*

*Template 1: Deployment Staging*
* RSL Schedule integration
* Deployment time and date
* Outstanding services tracking
* Confluence guide references

*Template 2: Staging Regression*
* Comprehensive app version tracking (Shopee, Seller, Lite)
* RN version availability time
* Test case spreadsheet link
* JIRA ticket references for Buyer & Seller
* Country and platform support details
* Internal target time tracking

*Template 3: Live Regression*
* Team master mentions (@mentions ready)
* Live TC spreadsheet
* SPMR ticket integration
* RN version with QR code link
* Time window configuration
* Simplified for quick execution

h2. Usage Examples

*Example 1: Creating Deployment Staging Message*

*Use Case:* Notify team about upcoming staging deployment

*Steps:*
# Open {{rn-regression-chat-generator.html}} in browser
# Click "Deployment Staging" tab (default)
# Fill in Version Number: {{2025.11.v4}}
# Fill in RSL Schedule Number: {{9540}}
# Click "Today" or "Tomorrow" for quick date fill
# Add deployment time: {{16.30}} Jakarta Time
# Click "Generate Chat"
# Review preview and click "Copy to Clipboard"
# Paste into SeaTalk/Slack channel

*Output:* Formatted message with all reference links included

{info}
All reference links are auto-included: Release Portal, Confluence Guide, Docs spreadsheet
{info}

*Example 2: Creating Staging Regression Message*

*Use Case:* Distribute staging regression tasks to team

*Steps:*
# Switch to "Staging Regression" tab
# Fill basic info: Version {{2025.11.v4}}, Date
# Fill app versions (or use defaults)
# Add test case spreadsheet URL
# Add JIRA ticket URLs
# Specify RN available time
# Click "Generate Chat"
# Copy and distribute to team

*Output:* Comprehensive message with version info, test cases, and all platform details

*Example 3: Creating Live Regression Message*

*Use Case:* Quick live regression announcement with team mentions

*Steps:*
# Switch to "Live Regression" tab
# Fill team master names (Buyer, Order Ops, Seller, Promotion)
# Set date (use "Next Wednesday" for quick fill)
# Add spreadsheet and JIRA links
# Set time window (default 15:00-17:00 WIB)
# Generate and copy

*Output:* Message ready with @mentions placeholders and all required info
