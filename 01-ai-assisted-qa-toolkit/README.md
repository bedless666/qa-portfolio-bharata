## 📋 Overview

This project showcases **AI-assisted QA engineering** capabilities through two distinct sub-projects that demonstrate the intersection of **AI prompting**, **technical problem-solving**, and **quality assurance thinking**.

**Key Innovation:** Every component in this toolkit was created using **AI prompting** (Cursor AI, ChatGPT), demonstrating advanced prompt engineering and AI collaboration skills essential for modern QA engineering.

---

## 🎯 Sub-Projects

### 1. [Japanese N5 Learning Presentations](./01-japanese-n5-learning/)
**Interactive language learning tool created entirely through AI prompting**

- **Purpose:** Self-paced Japanese language learning with interactive presentations
- **Technology:** HTML5, CSS3, JavaScript (AI-generated)
- **Content:** 23 interactive presentations covering Japanese N5 curriculum (Bab 1-40)
- **QA Relevance:** Demonstrates ability to use AI for creating test documentation, training materials, and interactive user guides

**Key Features:**
- ✅ Fully self-contained (no external dependencies)
- ✅ Interactive navigation and progress tracking
- ✅ Responsive design for multiple devices
- ✅ Created through iterative AI prompting and refinement

### 2. [N5 Quiz Tools](./02-n5-quiz-tools/)
**Interactive quiz and drill tools for Japanese N5 learning**

- **Purpose:** Practice and assessment tools for Japanese N5 vocabulary and grammar
- **Technology:** HTML5, CSS3, JavaScript (AI-generated)
- **Content:** Custom quiz interface and drill tool
- **QA Relevance:** Shows ability to create interactive test tools and assessment interfaces

**Key Features:**
- ✅ Custom quiz generation with configurable parameters
- ✅ Drill tool for repetitive practice
- ✅ Fully self-contained with no external dependencies
- ✅ Created through AI-assisted development

### 3. [HTML Prompting Interfaces](./03-html-prompting-interfaces/)
**Themed interactive interfaces showcasing AI-driven UI generation**

- **Purpose:** Demonstrate AI's capability to generate complex, themed user interfaces
- **Technology:** HTML5, CSS3, JavaScript (100% AI-generated)
- **Themes:** Pokemon, Fallout, Suikoden, Nexus AI, Bishi Bashi
- **QA Relevance:** Shows ability to rapidly prototype test interfaces, mock UIs for testing, and create visual test documentation

**Key Features:**
- ✅ 5 distinct themed interfaces with unique aesthetics
- ✅ Zero external dependencies (fully standalone)
- ✅ Production-ready code quality
- ✅ Created entirely through prompt engineering
